# Privacy
Training, feature extraction and prediction run locally. No account or analytics is required. Raw examples, model features and device recordings are stored in your browser until explicitly deleted or browser storage is evicted. Capture starts only on your action; file ingestion remains available when device permissions are denied.

External requests: explicitly downloaded image encoder weights contact listed model hosts; encrypted image link sharing contacts the operator-configured relay; WebRTC contacts the peer and any ICE servers you supply. These parties may see network metadata. P2P shares a selected model, not the dataset, only after explicit send/import actions.

Full backups are unencrypted private files. Model files can disclose labels/features and training-derived statistics. Keep both private unless deliberately sharing. Browser/app deletion cannot revoke copies already downloaded by you or another person. See docs/data-lifecycle.md and docs/threat-model.md. This source release makes no legal/regulatory compliance certification.
