PHASE 2 WORKING FEATURES
------------------------
1. Production offline app shell
   - Build-generated service worker precaches JS/CSS including lazy routes.
   - Revision includes worker template, public shell resources and emitted assets.
   - A failed new cache installation does not replace the active shell cache.
   - Waiting updates do not force skipWaiting. Explicit update UI uses Web Locks
     to coordinate active training/download/backup tasks across same-origin tabs.
   - Retained prior shell chunks can serve already-open older tabs. Old shell caches
     are not automatically purged yet; this favors compatibility over disk cleanup.
2. Persistent encoder pack
   - Exact 5-file MobileNet V2 pack: JSON plus four weight shards, about 14 MB.
   - SHA-256 and byte-size pins were obtained from actual downloaded assets.
   - Streamed bounded downloads, cancel, staging cache, one-pointer commit.
   - Each cached artifact is integrity-checked before use. No unverified fallback.
   - TensorFlow.js IOHandler loads directly from verified Cache Storage, so cold-page
     offline training/inference does not depend on remote model endpoints.
3. Full project backup and restore
   - Includes normalized JPEG samples, classes, all model versions, active selection
     and pending feedback; model-only export remains separate.
   - Explicit consent before exporting unencrypted image-containing backups.
   - Bounded JSON (no ZIP decompression), schema/shape checks, image SHA checks,
     JPEG decoding and 768px dimension limits before atomic database writes.
   - Always creates a new project, remapping record/model IDs. Never overwrites an
     existing project. Failed parsing/validation leaves existing projects intact.
4. Reviewed evolution
   - Explicit consent saves the prediction image and corrected class into a local
     queue. Review before approving. No silent dataset collection or retraining.
   - Approval moves the item into the dataset; discard deletes only the queue item.
   - Retrain manually, compare saved versions, then activate or roll back a model.
   - Byte-level duplicate detection prevents the same normalized image being added
     twice to a project, even with different labels. It is not semantic detection.
5. Honest comparison
   - Training artifacts now record dataset and actual validation-set fingerprints.
   - Comparison warns when held-out image sets/classes differ or metadata is absent.
   - Phase 1 models remain accepted; their comparison provenance is simply unknown.
6. Additive DB migration, focused tests, and matching responsive dark UI.

BOUNDARIES AND LIMITS — DO NOT HIDE THESE FROM THE USER
-------------------------------------------------------
This phase is real code, but the entire planned multi-modality product is NOT done.
No encrypted online sharing, WebRTC, non-image training, worker-isolated training,
continuous camera streaming, independent test-set UI, resumable training or universal
hardware guarantee yet. Training still uses asynchronous main-thread TFJS work.
WebGL is preferred with CPU fallback; WebGPU is not a claimed training backend.

Browser storage/caches can be cleared/evicted. Persistent-storage requests do not
replace backups. Cache corruption is detected; user can remove/reinstall the pack.
If the upstream model changes, pins intentionally fail closed; investigate and review
license/provenance before intentionally updating them. Do not disable hash checks.
Encoder-source requests expose connection metadata; your images are not uploaded.

Backups contain sensitive image data and are NOT ENCRYPTED. Limits: 1,000 samples,
100 queued feedback items, 50 model versions, 32 MB image data / 64 MB total JSON.
A model-only export is not a dataset backup. Both models and labels can leak info.
Validation performance is not independent test performance, and scores are not
calibrated probabilities. Fingerprints do not remove model-selection bias or detect
near-duplicate frames. Staged downloads are cancellable, not resumable across reloads.

Updates without Web Locks: close ALL NEURON tabs and reopen to activate the waiting
worker safely. Guarded tasks include training, encoder downloads and backup work;
this is not a general database lock against every simultaneous manual tab edit.

import { defineConfig, transformWithEsbuild, type Plugin } from "vite";
import react from "@vitejs/plugin-react";
import { readFileSync } from "node:fs";
import { createHash } from "node:crypto";
function offlineShell(): Plugin {
  return {
    name: "neuron-offline-shell",
    apply: "build",
    enforce: "post",
    async generateBundle(_, bundle) {
      const paths = [
        "/offline.html",
        "/favicon.svg",
        "/manifest.webmanifest",
        ...Object.keys(bundle)
          .filter((p) => !p.endsWith(".map"))
          .map((p) => "/" + p),
      ].sort();
      const workerTemplate = readFileSync(
        new URL("./src/pwa/service-worker.ts", import.meta.url),
        "utf8",
      );
      const publicRevision = [
        "offline.html",
        "favicon.svg",
        "manifest.webmanifest",
      ]
        .map((name) =>
          readFileSync(new URL("./public/" + name, import.meta.url), "utf8"),
        )
        .join("\n");
      const revision = createHash("sha256")
        .update(workerTemplate)
        .update(publicRevision)
        .update(paths.join("\n"))
        .update(
          String(
            bundle["index.html"]?.type === "asset"
              ? bundle["index.html"].source
              : "",
          ),
        )
        .digest("hex")
        .slice(0, 16);
      const source = readFileSync(
        new URL("./src/pwa/service-worker.ts", import.meta.url),
        "utf8",
      )
        .replace("__NEURON_PRECACHE__", JSON.stringify(paths))
        .replace("__NEURON_REVISION__", revision);
      const compiled = await transformWithEsbuild(source, "service-worker.ts", {
        loader: "ts",
        target: "es2022",
        minify: true,
      });
      this.emitFile({
        type: "asset",
        fileName: "service-worker.js",
        source: compiled.code,
      });
    },
  };
}
export default defineConfig({
  plugins: [react(), offlineShell()],
  server: { host: "0.0.0.0", allowedHosts: [".e2b.app", "localhost"] },
  preview: { host: "0.0.0.0", allowedHosts: [".e2b.app", "localhost"] },
  build: {
    target: "es2022",
    rollupOptions: {
      output: {
        manualChunks(id) {
          if (id.includes("@tensorflow")) return "tensorflow";
        },
      },
    },
  },
});

import { openDB, type DBSchema } from "idb";
import type { Project, Sample, ModelVersion, FeedbackItem } from "./types";
export interface NeuronDB extends DBSchema {
  projects: { key: string; value: Project };
  samples: { key: string; value: Sample; indexes: { "by-project": string } };
  versions: {
    key: string;
    value: ModelVersion;
    indexes: { "by-project": string };
  };
  feedback: {
    key: string;
    value: FeedbackItem;
    indexes: { "by-project": string };
  };
}
let connection: ReturnType<typeof openDB<NeuronDB>> | undefined;
export function database() {
  if (!("indexedDB" in globalThis))
    throw new Error("IndexedDB unavailable. Use a normal browser window.");
  return (connection ??= openDB<NeuronDB>("neuron-local", 2, {
    upgrade(db, oldVersion) {
      if (oldVersion < 1) {
        db.createObjectStore("projects", { keyPath: "id" });
        db.createObjectStore("samples", { keyPath: "id" }).createIndex(
          "by-project",
          "projectId",
        );
        db.createObjectStore("versions", { keyPath: "id" }).createIndex(
          "by-project",
          "projectId",
        );
      }
      if (oldVersion < 2)
        db.createObjectStore("feedback", { keyPath: "id" }).createIndex(
          "by-project",
          "projectId",
        );
    },
    blocking() {
      connection?.then((db) => db.close());
      connection = undefined;
    },
    terminated() {
      connection = undefined;
    },
  }));
}
export async function closeDatabase() {
  const db = await connection;
  db?.close();
  connection = undefined;
}
export async function saveProject(project: Project) {
  const db = await database();
  const tx = trackTransaction(db.transaction("projects", "readwrite"));
  const previous = await tx.store.get(project.id);
  // Creation uses a fresh UUID. Existing callers may edit metadata, but cannot inject raw samples.
  await tx.store.put({
    ...project,
    updatedAt: Math.max(project.updatedAt, previous?.updatedAt ?? 0),
  });
  await tx.done;
}
export async function listProjects() {
  return (await (await database()).getAll("projects")).sort(
    (a, b) => b.updatedAt - a.updatedAt,
  );
}
export async function getProject(id: string) {
  return (await database()).get("projects", id);
}
export async function listSamples(id: string) {
  return (await database()).getAllFromIndex("samples", "by-project", id);
}
export async function listVersions(id: string) {
  return (
    await (await database()).getAllFromIndex("versions", "by-project", id)
  ).sort((a, b) => b.createdAt - a.createdAt);
}
export async function deleteProject(id: string) {
  const db = await database();
  const tx = trackTransaction(
    db.transaction(
      ["projects", "samples", "versions", "feedback"],
      "readwrite",
    ),
  );
  await tx.objectStore("projects").delete(id);
  for (const name of ["samples", "versions", "feedback"] as const)
    for (const key of await tx
      .objectStore(name)
      .index("by-project")
      .getAllKeys(id))
      await tx.objectStore(name).delete(key);
  await tx.done;
}
export async function commitVersion(version: ModelVersion) {
  const db = await database();
  const tx = trackTransaction(
    db.transaction(["projects", "versions"], "readwrite"),
  );
  const project = await tx.objectStore("projects").get(version.projectId);
  if (!project) {
    tx.abort();
    await tx.done.catch(() => {});
    throw new Error("Project no longer exists.");
  }
  await tx.objectStore("versions").add(version);
  await tx
    .objectStore("projects")
    .put({ ...project, activeVersionId: version.id, updatedAt: Date.now() });
  await tx.done;

export async function sha256(value: Blob | ArrayBuffer | Uint8Array | string) {
  const data =
    typeof value === "string"
      ? new TextEncoder().encode(value)
      : value instanceof Blob
        ? await value.arrayBuffer()
        : value;
  const hash = await crypto.subtle.digest("SHA-256", data as BufferSource);
  return Array.from(new Uint8Array(hash), (b) =>
    b.toString(16).padStart(2, "0"),
  ).join("");
}

async function fetchBounded(url: string, limit: number, signal: AbortSignal) {
  const response = await fetch(url, {
    signal,
    cache: "no-store",

    throw new Error(`Asset download failed (${response.status}).`);

    chunks: Uint8Array[] = [];

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

  }
  const result = new Uint8Array(total);
  let offset = 0;
  for (const chunk of chunks) {
    result.set(chunk, offset);
    offset += chunk.length;
  }
  return result;
}

      !text(l.name, 64) ||
      labelIds.has(l.id) ||
      names.has(l.name.toLowerCase())
    )
      throw new Error("Invalid backup classes.");
    labelIds.add(l.id);
    names.add(l.name.toLowerCase());
  }
  if (
    ![b.project.createdAt, b.project.updatedAt, b.createdAt].every(
      Number.isFinite,
    ) ||
    !Array.isArray(b.samples) ||
    b.samples.length > 1000 ||
    !Array.isArray(b.versions) ||
    b.versions.length > 50 ||
    !Array.isArray(b.feedback) ||
    b.feedback.length > 100
  )
    throw new Error("Backup exceeds supported record limits.");
  const versionIds = new Set<string>();
  for (const v of b.versions) {
    if (
      !v ||
      !text(v.id) ||
      versionIds.has(v.id) ||
      v.projectId !== b.project.id ||
      !Number.isFinite(v.createdAt)
    )
      throw new Error("Invalid model version.");
    versionIds.add(v.id);
    validateArtifact(v.artifact);
  }
  if (b.project.activeVersionId && !versionIds.has(b.project.activeVersionId))
    throw new Error("Active model is missing from backup.");
  const allIds = new Set<string>();
  let chars = 0;
  for (const [list, feedback] of [
    [b.samples, false],
    [b.feedback, true],
  ] as const)
    for (const m of list) {
      if (
        !m ||
        !text(m.id) ||
        allIds.has(m.id) ||
        !labelIds.has(m.labelId) ||
        !Number.isFinite(m.createdAt) ||
        !validHash(m.hash) ||
        typeof m.data !== "string" ||
        m.data.length > 2 * 1024 * 1024 ||
        !/^[A-Za-z0-9+/]*={0,2}$/.test(m.data)
      )
        throw new Error("Invalid image record in backup.");
      if (
        feedback &&
        (!text(m.versionId) ||
          !versionIds.has(m.versionId!) ||
          typeof m.predictedLabel !== "string" ||
          m.predictedLabel.length > 64)
      )
        throw new Error("Invalid feedback record.");
      allIds.add(m.id);
      chars += m.data.length;
    }
  if (chars > Math.ceil((MEDIA_LIMIT * 4) / 3) + 4096)
    throw new Error("Backup images exceed the 32 MB media budget.");
  return b;
}
export async function encodeBackup(snapshot: Snapshot): Promise<Blob> {
  let bytes = 0;
  async function encode(s: Sample | FeedbackItem): Promise<Media> {
    bytes += s.blob.size;
    if (bytes > MEDIA_LIMIT)
      throw new Error(
        "This phase supports at most 32 MB of image/feedback data per backup.",
      );
    return {
      id: s.id,
      labelId: s.labelId,
      createdAt: s.createdAt,
      data: toBase64(await s.blob.arrayBuffer()),
      hash: await sha256(s.blob),
      ...("versionId" in s
        ? { versionId: s.versionId, predictedLabel: s.predictedLabel }
        : {}),
    };
  }
  const samples: Media[] = [],
    feedback: Media[] = [];
  for (const s of snapshot.samples) samples.push(await encode(s));
  for (const f of snapshot.feedback) feedback.push(await encode(f));
  const b: Backup = {
    format: "neuron-project",
    version: 1,
    project: snapshot.project,
    samples,
    feedback,
    versions: snapshot.versions,
    createdAt: Date.now(),
  };
  validateBackupShape(b);
  const blob = new Blob([JSON.stringify(b)], { type: "application/json" });
  if (blob.size > BACKUP_LIMIT)
    throw new Error("Backup exceeds the 64 MB file limit.");
  return blob;
}
export async function decodeBackup(file: Blob): Promise<Snapshot> {
  if (file.size > BACKUP_LIMIT)
    throw new Error("Backup exceeds the 64 MB file limit.");
  let raw: unknown;
  try {
    raw = JSON.parse(await file.text());
  } catch {
    throw new Error("Backup is not valid JSON.");
  }
  const b = validateBackupShape(raw),
    projectId = uid(),
    versionMap = new Map(b.versions.map((v) => [v.id, uid()]));
  async function media(m: Media) {
    const data = fromBase64(m.data);
    if ((await sha256(data)) !== m.hash)
      throw new Error("Backup image checksum mismatch. No data was restored.");
    const bytes = new Uint8Array(data);
    if (
      bytes.length < 4 ||
      bytes[0] !== 255 ||
      bytes[1] !== 216 ||
      bytes[2] !== 255
    )
      throw new Error("Only normalized JPEG images are supported in backups.");
    return new Blob([data], { type: "image/jpeg" });
  }
  const samples: Sample[] = [],
    feedback: FeedbackItem[] = [];
  for (const m of b.samples)
    samples.push({
      id: uid(),
      projectId,
      labelId: m.labelId,
      createdAt: m.createdAt,
      blob: await media(m),
      hash: m.hash,
    });
  for (const m of b.feedback)
    feedback.push({
      id: uid(),
      projectId,
      labelId: m.labelId,
      createdAt: m.createdAt,
      blob: await media(m),
      versionId: versionMap.get(m.versionId!)!,
      predictedLabel: m.predictedLabel!,
    });
  const project: Project = {
    id: projectId,
    name: (b.project.name.slice(0, 52) + " (restored)").slice(0, 64),
    labels: b.project.labels,
    createdAt: b.project.createdAt,
    updatedAt: Date.now(),
    activeVersionId: b.project.activeVersionId
      ? versionMap.get(b.project.activeVersionId)
      : undefined,
  };
  return {
    project,
    samples,
    feedback,
    versions: b.versions.map((v) => ({
      id: versionMap.get(v.id)!,
      projectId,
      createdAt: v.createdAt,
      artifact: validateArtifact(v.artifact),
    })),
  };
}

export async function decodeImage(blob: Blob): Promise<ImageBitmap> {
  try {
    return await createImageBitmap(blob, { imageOrientation: "from-image" });
  } catch {
    throw new Error(
      "Could not decode this image. Use a valid JPEG, PNG or WebP.",

export async function normalizeImage(file: File): Promise<Blob> {
  if (!["image/jpeg", "image/png", "image/webp"].includes(file.type))
    throw new Error(`${file.name}: only JPEG, PNG and WebP are supported.`);
  if (file.size > 15 * 1024 * 1024)
    throw new Error(`${file.name}: maximum upload size is 15 MB.`);
  const bitmap = await decodeImage(file);
  try {
    if (bitmap.width * bitmap.height > 40_000_000)
      throw new Error("Image exceeds the 40-megapixel safety limit.");
    const scale = Math.min(1, 768 / Math.max(bitmap.width, bitmap.height));
    const canvas = document.createElement("canvas");
    canvas.width = Math.max(1, Math.round(bitmap.width * scale));
    canvas.height = Math.max(1, Math.round(bitmap.height * scale));
    const ctx = canvas.getContext("2d");
    if (!ctx) throw new Error("Canvas unavailable.");
    ctx.fillStyle = "#fff";
    ctx.fillRect(0, 0, canvas.width, canvas.height);
    ctx.drawImage(bitmap, 0, 0, canvas.width, canvas.height);
    return await new Promise<Blob>((resolve, reject) =>
      canvas.toBlob(
        (b) => (b ? resolve(b) : reject(new Error("Image encoding failed."))),
        "image/jpeg",
        0.88,
      ),
    );
  } finally {
    bitmap.close();
  }
}
export async function addImages(
  projectId: string,
  labelId: string,
  files: File[],
  currentCount: number,
  onProgress: (n: number) => void,
) {
  if (currentCount + files.length > MAX_SAMPLES)
    throw new Error(
      `This phase supports at most ${MAX_SAMPLES} samples per project.`,
    );
  const errors: string[] = [];
  let saved = 0;
  for (const file of files) {
    try {
      const blob = await normalizeImage(file);
      const sample: Sample = {
        id: uid(),
        projectId,
        labelId,
        blob,
        createdAt: Date.now(),
      };
      sample.hash = await sha256(blob);
      const db = await database();
      // Lazily hash Phase 1 samples without recreating records deleted by another tab.
      for (const old of await db.getAllFromIndex(
        "samples",
        "by-project",
        projectId,
      )) {
        if (old.hash) continue;
        const hash = await sha256(old.blob);
        const update = trackTransaction(db.transaction("samples", "readwrite"));
        const current = await update.store.get(old.id);
        if (current) await update.store.put({ ...current, hash });
        await update.done;
      }
      const tx = trackTransaction(
        db.transaction(["projects", "samples"], "readwrite"),
      );
      const project = await tx.objectStore("projects").get(projectId);
      const current = await tx
        .objectStore("samples")
        .index("by-project")
        .getAll(projectId);
      if (
        !project ||
        !project.labels.some((l) => l.id === labelId) ||
        current.length >= MAX_SAMPLES ||
        current.some((s) => s.hash === sample.hash)
      ) {
        tx.abort();
        await tx.done.catch(() => {});
        throw new Error(
          !project
            ? "Project deleted."
            : current.some((s) => s.hash === sample.hash)
              ? "Duplicate image already exists in this project."
              : "Class changed or project sample limit reached.",
        );
      }
      await tx.objectStore("samples").add(sample);
      await tx
        .objectStore("projects")
        .put({ ...project, updatedAt: Date.now() });
      await tx.done;
      saved++;
    } catch (e) {
      errors.push(
        `${file.name}: ${e instanceof Error ? e.message : "Save failed"}`,
      );
      if (e instanceof DOMException && e.name === "QuotaExceededError") break;
    }
    onProgress(saved);
  }
  return { saved, errors };
}

export function random(seed: number) {
  return () => {
    seed |= 0;
    seed = (seed + 0x6d2b79f5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
export function splitIndices(labels: number[], seed: number) {
  const rng = random(seed),
    train: number[] = [],
    validation: number[] = [];
  for (const label of [...new Set(labels)]) {
    const indices = labels
      .map((v, i) => (v === label ? i : -1))
      .filter((i) => i !== -1);
    if (indices.length < 5)
      throw new Error("Every class needs at least 5 images.");
    for (let i = indices.length - 1; i > 0; i--) {
      const j = Math.floor(rng() * (i + 1));
      [indices[i], indices[j]] = [indices[j], indices[i]];
    }
    const count = Math.max(1, Math.floor(indices.length * 0.2));
    validation.push(...indices.slice(0, count));
    train.push(...indices.slice(count));
  }
  return { train, validation };
}
export function evaluate(
  actual: number[],
  predicted: number[],
  classes: number,
): Evaluation {
  if (!actual.length || actual.length !== predicted.length)
    throw new Error("Invalid evaluation data.");
  const matrix = Array.from({ length: classes }, () =>
    Array<number>(classes).fill(0),
  );
  let correct = 0;
  actual.forEach((a, i) => {
    const p = predicted[i];
    if (
      a < 0 ||
      a >= classes ||
      p < 0 ||
      p >= classes ||
      !Number.isInteger(a) ||
      !Number.isInteger(p)
    )
      throw new Error("Invalid prediction index.");
    matrix[a][p]++;
    if (a === p) correct++;
  });
  return { accuracy: correct / actual.length, matrix, total: actual.length };
}

    !Number.isFinite(options.learningRate)

    throw new Error("Invalid training settings.");

  const targets = samples.map((s) => ids.indexOf(s.labelId));
  if (targets.some((i) => i < 0))
    throw new Error("Dataset contains an unknown class.");

  const check = () => {
    if (signal.aborted)
      throw new DOMException("Training cancelled.", "AbortError");
  };
  const vectors: Float32Array[] = [];
  const metrics: EpochMetric[] = [];
  progress({
    stage: "Downloading / loading image encoder",
    done: 0,
    total: samples.length,
    metrics: [],
  });
  for (let i = 0; i < samples.length; i++) {
    check();
    vectors.push(await embed(samples[i].blob));
    progress({
      stage: "Extracting image features",
      done: i + 1,
      total: samples.length,
      metrics: [],
    });
    await tf.nextFrame();
  }
  check();

    tf.tensor2d(
      indices.map((i) => Array.from(vectors[i])),
      [indices.length, 1280],
    );

    tf.tidy(() =>
      tf.oneHot(
        tf.tensor1d(
          indices.map((i) => targets[i]),
          "int32",
        ),
        ids.length,
      ),
    );

    y: tf.Tensor | undefined,
    vx: ReturnType<typeof makeX> | undefined,
    vy: tf.Tensor | undefined;

  const optimizer = tf.train.adam(options.learningRate);

    x = makeX(training);
    y = makeY(training);
    vx = makeX(validation);
    vy = makeY(validation);

      optimizer,
      loss: "categoricalCrossentropy",
      metrics: ["accuracy"],
    });

      epochs: options.epochs,
      batchSize: Math.min(16, training.length),
      shuffle: true,
      validationData: [vx, vy],
      callbacks: {
        onBatchEnd: async () => {
          if (signal.aborted) head.stopTraining = true;
          await tf.nextFrame();
        },
        onEpochEnd: async (epoch, logs) => {
          const metric: EpochMetric = {
            epoch: epoch + 1,
            loss: Number(logs?.loss ?? 0),
            accuracy: Number(logs?.acc ?? logs?.accuracy ?? 0),
            valLoss: Number(logs?.val_loss ?? 0),
            valAccuracy: Number(logs?.val_acc ?? logs?.val_accuracy ?? 0),
          };
          if (!Object.values(metric).every(Number.isFinite)) {
            head.stopTraining = true;
            throw new Error("Training diverged. Reduce learning rate.");
          }
          metrics.push(metric);
          progress({
            stage: "Training classifier",
            done: epoch + 1,
            total: options.epochs,
            metrics: [...metrics],
          });
        },
      },
    });
    check();
    const predicted = tf.tidy(() =>
      (head.predict(vx!) as tf.Tensor).argMax(-1),
    );
    let indices: number[];
    try {
      indices = Array.from(await predicted.data());
    } finally {
      predicted.dispose();
    }

      validation.map((i) => targets[i]),
      indices,
      ids.length,
    );

    const weights = head.getWeights();
    const named: tf.NamedTensorMap = {};
    weights.forEach((w, i) => (named[`head_${i}`] = w));
    const encoded = await tf.io.encodeWeights(named);
    check();

      samples.map(async (s) => ({
        hash: await sha256(s.blob),
        labelId: s.labelId,
      })),
    );
    const provenance = {
      datasetHash: await sha256(
        JSON.stringify({
          labels: project.labels,
          rows: [...rows].sort((a, b) =>
            (a.hash + a.labelId).localeCompare(b.hash + b.labelId),
          ),
        }),
      ),
      validationHash: await sha256(
        JSON.stringify({
          labels: project.labels,
          rows: validation
            .map((i) => rows[i])
            .sort((a, b) =>
              (a.hash + a.labelId).localeCompare(b.hash + b.labelId),
            ),
        }),
      ),
      seed: options.seed,
      sampleCount: samples.length,
    };
    return {
      provenance,
      format: "neuron-image",
      version: 1,
      encoder: "mobilenet-v2-1.0",
      embeddingSize: 1280,
      labels: structuredClone(project.labels),
      weightSpecs: encoded.specs as ModelArtifact["weightSpecs"],
      weightData: toBase64(encoded.data),
      epochs: metrics,
      evaluation,
      createdAt: Date.now(),
    };
  } finally {
    x?.dispose();
    y?.dispose();
    vx?.dispose();
    vy?.dispose();
    head.dispose();
    optimizer.dispose();
  }
}

    a.epochs.length > 100

# NEURON — Phase 2

Requires the 40-file Phase 1 baseline plus this 40-file Phase 2 update. Do not delete unrelated scaffold files. Node.js 20.19+ or 22.12+, pnpm 9.15.5.

## Run and verify

    pnpm install
    pnpm typecheck
    pnpm test
    pnpm build
    pnpm dev

## Test offline on the PRODUCTION build

    pnpm build
    pnpm --filter @neuron/web preview --port 4173

Open http://localhost:4173. In Settings wait for Application shell → Installed; download the ~14 MB image encoder and wait for Verified. Then disconnect networking and reload. Local projects, training, model import/export and inference are available subject to browser APIs/hardware. Vite development deliberately does not install a service worker. A production service worker precaches hashed application bundles including lazy routes; the encoder is separately SHA-256 pinned. If upstream assets change unexpectedly installation fails closed. Investigate/model-license-review before updating pins, never disable verification.

## Origins matter

Browser storage is scoped to scheme + hostname + port. Projects at localhost:5173 do not automatically appear at localhost:4173, and a deployed domain has separate storage too. This does not mean the projects were deleted. With Phase 2 running on the original origin, export a full project backup there, then restore it on the new origin. Model caches are downloaded separately for each origin. Do not clear site data as a troubleshooting shortcut. Development and production previews should use different ports so a production service worker does not intercept a development session.

## Phase 2 features

- Production app-shell offline caching and explicit safe waiting-update UI.
- Streaming bounded encoder downloads, cancellation, staging-cache commit, cryptographic verification on installation and every cached load. Cache corruption yields an actionable recovery path.
- Full project JSON backups: normalized images, feedback, model versions and active selection. Restores always create a NEW project and remap IDs in a single transaction, after validating checksums, schemas and decoding bounded JPEG images. No executable graphs are imported.
- Explicitly consented prediction feedback → review queue → approve to dataset → manual retrain → choose/rollback model.
- Dataset duplicate detection based on normalized JPEG bytes. This is NOT semantic/near-duplicate detection.
- Model-version comparisons warn when validation fingerprints differ or are missing (legacy Phase 1 artifacts remain usable).
- IndexedDB v1→v2 additive migration preserves existing projects/images/models; adds a feedback store.

Backup limits: 1,000 samples, 100 feedback items, 50 model versions, 32 MB images and a 64 MB JSON file. Limits deliberately bound memory use. Backups are NOT encrypted and contain your images. A model-only export still contains no samples. Do not confuse the two.

## Security and lifecycle

No account or cloud training. Download requests go to Google/Kaggle endpoints; images are never uploaded by local workflows. Explicit local export can reveal sensitive data. Browser storage and caches remain evictable; keep backups outside the browser. Existing shell caches are retained to avoid breaking old open tabs; storage cleanup for old shell versions is not automated in this phase.

Safe explicit updates coordinate running training/download/backup jobs using Web Locks across same-origin tabs. If Web Locks is unavailable, close all NEURON tabs and reopen to apply updates. A first installation claims clients but never forces a waiting update into an existing session. A future browser restart or closing all tabs can also activate a waiting service worker normally.

The app assumes deployment at origin root /. HTTPS/localhost required. Hosting response headers need provider-specific configuration; public/\_headers is honored only by compatible hosts. Keep correct JavaScript MIME types and do not rewrite service-worker.js to HTML. This phase does not deploy the original scaffold's infrastructure stubs.

## Still not completed

Training remains on the main browser thread with async yields. No encrypted public share links, WebRTC, non-image modalities, independent test-dataset UI, continuous camera streaming, semantic duplicate detection, encrypted backups, resumable training, browser-wide storage locks against all manual edits, or universal hardware/performance guarantee. Model evolution is explicit reviewed retraining, never silent self-modification. An accessibility/security/model-license audit and physical-device validation remain release gates. Mobile/OS PWA installation support varies; SVG manifest icon support alone does not certify installability on every device.

## Numerical meaning

Frozen MobileNet V2 [0,1] input normalization matches the published TFJS encoder configuration. Model training updates the local softmax head. Validation data stays out of fit. Fingerprints identify exact normalized bytes and class vocabulary; matching sets do not create an independent test or remove selection bias. Softmax scores are relative outputs, not calibrated certainty.
