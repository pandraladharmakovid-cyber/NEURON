WHAT PHASE 3 IMPLEMENTS
------------------------
- Saved model -> explicit consent -> fresh AES-256-GCM encryption -> actual relay
  upload -> expiring link. Every upload uses a fresh CSPRNG key and 96-bit IV, with
  authenticated protocol-specific additional data and a 128-bit authentication tag.
- Whitelisted model fields only. Unknown imported fields are stripped. Project images
  and feedback are not part of the encrypted payload. Model weights may still reveal
  training information, which the consent UI explicitly warns about.
- The encryption key is only in the URL fragment; it is never an API parameter or
  upload header. Recipient strips the incoming key from the visible address bar and
  keeps it in memory. Preserve the ORIGINAL secret link if reopening is needed.
- Recipient explicitly downloads/decrypts, validates the supported artifact, inspects
  its metadata, then imports as a NEW local project. No arbitrary executable model
  graphs or scripts are accepted. Existing local projects are not overwritten.
- Independent deletion capability: a separate random 256-bit token, stored locally
  and sent only in the DELETE Authorization header. Relay stores its SHA-256 hash.
- Downloadable/importable sensitive deletion receipts, separate from project backups.
  Conflicting receipts cannot overwrite existing access/deletion capabilities.
- Local receipt management clearly distinguishes Revoke remote link from Forget local
  receipt. Deleting a project is NOT remote revocation. Lost tokens cannot be recovered
  without a saved receipt. Expiry remains enforced even if a receipt is lost.
- A real Cloudflare Worker router, private R2 ciphertext storage, a transactional
  SQLite-backed Durable Object budget service and an hourly expiry-cleanup handler.
- Strict body sizes, bounded response parsing, canonical secret encodings, route and
  TTL validation, explicit same-origin mutation policy, no-store API responses and
  a service-worker bypass for /api/shares. No secret route data is rendered in nav.
- A usable same-origin development/production-preview proxy and fail-closed cloud
  configuration, not an invented public endpoint or a silently created cloud resource.

REAL LIMITS AND SECURITY BOUNDARIES
------------------------------------
This is a working phase, NOT a claim that the entire NEURON roadmap is finished,
perfect, audited or publicly deployed. Keep later features labeled honestly.

The relay sees client connection metadata, ciphertext length, timing and expiry.
It does not get the encryption key through this protocol. Any holder of the full
secret link can decrypt or reshare. Encryption is not guaranteed availability.
Compromised frontend code, browser extensions, endpoints and recipients are outside
this cryptographic boundary. Do not add analytics/error logs that capture links,
fragments, Authorization headers, receipt files or plaintext model payloads.

A trained model can leak information. "No source image transfer" is not a guarantee
of anonymity or privacy against model inference attacks. Labels/model names can also
be sensitive. Receipts contain BOTH access and deletion capabilities: keep them private.
Project backups deliberately do not contain them; export receipts separately.

Link lifetimes accepted by protocol: 60 seconds, 15 minutes, 1 hour, 24 hours. UI shows
15 minutes / 1 hour / 24 hours. API download denies expired objects immediately and
removes stale data on access. Hourly cron cleans unaccessed expired ciphertext. Cloud
provider backup/retention policy still applies. Revocation cannot erase data someone
already downloaded/imported. The browser verification explicitly demonstrates that.
If an upload is cancelled after server receipt but before the response, an unconfirmed
object can remain until expiry because its reference was not received. No fake claim
of guaranteed cancellation/revocation is made for that distributed-systems case.

Envelope maximum: 8 MB +64 bytes. Model payload maximum: 8 MB. Receipts: 16 KB import.
Worker validates framing and size, NOT the encrypted content's semantics (it lacks
the key). A malicious direct client can upload arbitrary framed bytes. Official
client payload sanitization is not proof that all Internet traffic is a model.

Anonymous fixed-hour budgets, enforced atomically by Durable Object:
  Per client: 3 upload reservations, 30 downloads, 20 deletions per hour.
  Global:     50 uploads, 500 downloads, 500 deletions per hour.
Client keys are salted hashes of Cloudflare's connecting IP; NAT users share limits.
Development may group local users under a local IP. A request rejected after reserving
budget is intentionally not refunded. Restarting/clearing local emulator state is NOT
an application quota bypass feature and is not a production reset mechanism.

Origin/header checks defend browser-origin misuse, not non-browser clients able to
forge HTTP headers. Quotas cannot cap every edge/DO/R2 cost or prevent every DoS.
Provider edge rate limits, billing alerts, kill switches, retention/governance and
abuse review are MANDATORY before exposing anonymous uploads publicly.

          .map((p) => "/" + p),

      const workerTemplate = readFileSync(
        new URL("./src/pwa/service-worker.ts", import.meta.url),
        "utf8",
      );
      const publicRevision = [
        "offline.html",
        "favicon.svg",
        "manifest.webmanifest",
      ]

        )
        .join("\n");
      const revision = createHash("sha256")
        .update(workerTemplate)
        .update(publicRevision)
        .update(paths.join("\n"))

              ? bundle["index.html"].source
              : "",
          ),
        )
        .digest("hex")
        .slice(0, 16);

        .replace("__NEURON_REVISION__", revision);

        loader: "ts",
        target: "es2022",
        minify: true,
      });

        fileName: "service-worker.js",

const AAD = new TextEncoder().encode("NEURON-MODEL-SHARE:v1");
export const MAX_CIPHER_BYTES = 8 * 1024 * 1024 + 64;
export function base64url(bytes: Uint8Array) {
  let raw = "";
  for (let i = 0; i < bytes.length; i += 8192)
    raw += String.fromCharCode(...bytes.subarray(i, i + 8192));
  return btoa(raw).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}
export function unbase64url(value: string, bytes: number) {
  if (
    !/^[A-Za-z0-9_-]+$/.test(value) ||
    value.length !== Math.ceil((bytes * 4) / 3)
  )
    throw new Error("Invalid secret encoding.");
  let raw: string;
  try {
    raw = atob(
      value.replace(/-/g, "+").replace(/_/g, "/") +
        "=".repeat((4 - (value.length % 4)) % 4),
    );
  } catch {
    throw new Error("Invalid secret encoding.");
  }
  const data = Uint8Array.from(raw, (c) => c.charCodeAt(0));
  if (data.length !== bytes || base64url(data) !== value)
    throw new Error("Noncanonical secret encoding.");
  return data;
}
export function randomSecret() {
  return base64url(crypto.getRandomValues(new Uint8Array(32)));
}
export async function secretHash(value: string) {
  unbase64url(value, 32);
  const bytes = await crypto.subtle.digest(
    "SHA-256",
    new TextEncoder().encode(value),
  );
  return Array.from(new Uint8Array(bytes), (b) =>
    b.toString(16).padStart(2, "0"),
  ).join("");
}
export async function encryptModel(plaintext: Uint8Array) {
  if (plaintext.length > MAX_CIPHER_BYTES - 32)
    throw new Error("Model is too large to share.");
  const secret = randomSecret(),
    iv = crypto.getRandomValues(new Uint8Array(12));
  const key = await crypto.subtle.importKey(
    "raw",
    unbase64url(secret, 32),
    { name: "AES-GCM" },
    false,
    ["encrypt"],
  );
  const encrypted = await crypto.subtle.encrypt(
    { name: "AES-GCM", iv, additionalData: AAD, tagLength: 128 },
    key,
    plaintext as BufferSource,
  );
  const output = new Uint8Array(16 + encrypted.byteLength);
  output.set(MAGIC);
  output.set(iv, 4);
  output.set(new Uint8Array(encrypted), 16);
  return { secret, bytes: output };
}

async function bounded(response: Response, limit: number) {
  if (!response.body) throw new Error("Relay returned an empty response.");
  const reader = response.body.getReader(),
    chunks: Uint8Array[] = [];
  let size = 0;
  try {
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      size += value.byteLength;
      if (size > limit) {
        await reader.cancel();
        throw new Error("Relay response exceeds the safety limit.");
      }
      chunks.push(value);
    }
  } finally {
    reader.releaseLock();
  }
  const result = new Uint8Array(size);
  let i = 0;
  for (const chunk of chunks) {
    result.set(chunk, i);
    i += chunk.length;
  }
  return result;
}

import { unbase64url } from "./crypto";
export type ShareReceipt = {
  format: "neuron-share-receipt";
  version: 1;
  id: string;
  projectId: string;
  versionId: string;
  name: string;
  createdAt: number;
  expiresAt: number;
  deleteToken: string;
  link: string;
};
const db = () =>
  openDB("neuron-sharing", 1, {
    upgrade(database) {
      database.createObjectStore("receipts", { keyPath: "id" });
    },
  });
export function validateReceipt(value: unknown): ShareReceipt {
  const r = value as ShareReceipt;
  if (
    !r ||
    r.format !== "neuron-share-receipt" ||
    r.version !== 1 ||
    !validShareId(r.id ?? "") ||
    typeof r.projectId !== "string" ||
    r.projectId.length > 100 ||
    typeof r.versionId !== "string" ||
    r.versionId.length > 100 ||
    typeof r.name !== "string" ||
    !r.name.trim() ||
    r.name.length > 64 ||
    !Number.isFinite(r.createdAt) ||
    !Number.isFinite(r.expiresAt) ||
    r.expiresAt <= r.createdAt ||
    typeof r.link !== "string" ||
    r.link.length > 2048
  )
    throw new Error("Invalid share receipt.");
  unbase64url(r.deleteToken, 32);
  if (parseShareLink(r.link).id !== r.id)
    throw new Error("Receipt link does not match its reference.");
  return structuredClone(r);
}
export async function saveReceipt(receipt: ShareReceipt) {
  const database = await db();
  try {
    const safe = validateReceipt(receipt);
    const tx = database.transaction("receipts", "readwrite");
    void tx.done.catch(() => {});
    const existing = await tx.store.get(safe.id);
    if (
      existing &&
      (existing.link !== safe.link || existing.deleteToken !== safe.deleteToken)
    ) {
      tx.abort();
      await tx.done.catch(() => {});
      throw new Error(
        "A conflicting receipt already exists. Existing access/deletion capabilities were not replaced.",
      );
    }
    await tx.store.put(safe);
    await tx.done;
  } finally {
    database.close();
  }
}
export async function listReceipts(): Promise<ShareReceipt[]> {
  const database = await db();
  try {
    return (await database.getAll("receipts"))
      .map(validateReceipt)
      .sort((a, b) => b.createdAt - a.createdAt);
  } finally {
    database.close();
  }
}
export async function forgetReceipt(id: string) {
  const database = await db();
  try {
    await database.delete("receipts", id);
  } finally {
    database.close();
  }
}
export async function importReceipt(file: File, origin: string) {
  if (file.size > 16384) throw new Error("Receipt exceeds the 16 KB limit.");
  const receipt = validateReceipt(JSON.parse(await file.text()));
  if (parseShareLink(receipt.link).origin !== origin)
    throw new Error(
      "This receipt belongs to another application origin. Open that origin to manage it.",
    );
  await saveReceipt(receipt);
  return receipt;
}

export async function createShare(
  project: Project,
  version: ModelVersion,
  ttl: number,
  origin: string,
  signal: AbortSignal,
) {
  return runActivity(async () => {
    if (version.projectId !== project.id)
      throw new Error("Model does not belong to this project.");
    const token = randomSecret(),
      encoded = encodeShared(project.name, version.artifact),
      encrypted = await encryptModel(encoded);
    signal.throwIfAborted();
    const remote = await uploadEncrypted(
      encrypted.bytes,
      await secretHash(token),
      ttl,
      signal,
    );
    const receipt: ShareReceipt = {
      format: "neuron-share-receipt",
      version: 1,
      id: remote.id,
      projectId: project.id,
      versionId: version.id,
      name: project.name,
      createdAt: remote.expiresAt - ttl * 1000,
      expiresAt: remote.expiresAt,
      deleteToken: token,
      link: shareLink(origin, remote.id, encrypted.secret),
    };
    let persisted = true;
    try {
      await saveReceipt(receipt);
    } catch {
      persisted = false;
    }
    return { receipt, persisted };
  });
}
export async function receiveShare(
  id: string,
  secret: string,
  signal: AbortSignal,
) {
  return runActivity(async () =>
    decodeShared(
      await decryptModel(await downloadEncrypted(id, signal), secret),
    ),
  );
}
export async function importReceived(model: SharedModel) {
  return runActivity(async () => {
    const safe = decodeShared(encodeShared(model.name, model.artifact)),
      now = Date.now(),
      project: Project = {
        id: uid(),
        name: safe.name,
        labels: safe.artifact.labels,
        createdAt: now,
        updatedAt: now,
      },
      version: ModelVersion = {
        id: uid(),
        projectId: project.id,
        artifact: safe.artifact,
        createdAt: now,
      };
    project.activeVersionId = version.id;
    const db = await database(),
      tx = trackTransaction(
        db.transaction(["projects", "versions"], "readwrite"),
      );
    await tx.objectStore("projects").add(project);
    await tx.objectStore("versions").add(version);
    await tx.done;
    return project;
  });
}
export async function revokeShare(receipt: ShareReceipt, origin: string) {
  if (parseShareLink(receipt.link).origin !== origin)
    throw new Error(
      "Manage this receipt from its original application origin.",
    );
  return runActivity(async () => {
    await revokeEncrypted(receipt.id, receipt.deleteToken);
    await forgetReceipt(receipt.id);
  });
}

export async function readCiphertext(request: Request) {

    .get("Content-Type")

type Counts = { upload: number; download: number; delete: number };
type Budget = { hour: number; global: Counts; clients: Record<string, Counts> };
const empty = (): Counts => ({ upload: 0, download: 0, delete: 0 });
const PER_CLIENT: Counts = { upload: 3, download: 30, delete: 20 };
const GLOBAL: Counts = { upload: 50, download: 500, delete: 500 };
export class RateLimiter {
  constructor(private state: DurableObjectState) {}
  async fetch(request: Request) {
    let input: { client?: string; action?: keyof Counts };
    try {
      input = await request.json();
    } catch {
      return new Response("Invalid budget request", { status: 400 });
    }
    const action = input.action,
      client = input.client;
    if (
      !action ||
      !["upload", "download", "delete"].includes(action) ||
      !client ||
      !/^[a-f0-9]{64}$/.test(client)
    )
      return new Response("Invalid budget request", { status: 400 });

      const hour = Math.floor(Date.now() / 3600000);
      let budget = await tx.get<Budget>("budget");
      if (!budget || budget.hour !== hour)
        budget = { hour, global: empty(), clients: {} };
      if (budget.global[action] >= GLOBAL[action]) return false;
      const personal = budget.clients[client] ?? empty();
      if (personal[action] >= PER_CLIENT[action]) return false;
      // The global budgets bound successful new client entries to <=1050/hour.
      budget.global[action]++;
      personal[action]++;

# NEURON encrypted model sharing — protocol v1

Training remains local. Sharing is optional and online. It distributes the selected supported image classifier, never the project dataset. A trained model can still reveal sensitive information.

## Secrets and framing

The sender creates a fresh AES-256-GCM key and independent 256-bit deletion token using Web Crypto's CSPRNG. Ciphertext bytes are: ASCII NRN, version byte 1, 12-byte random IV, AES-GCM ciphertext with a 128-bit tag. Authenticated additional data is `NEURON-MODEL-SHARE:v1`. Payload is bounded UTF-8 JSON: format/version, model name and a whitelisted validated artifact. Unknown imported fields are stripped before encryption.

A relay POST receives ciphertext, SHA-256 of the deletion token and requested TTL. It generates a 192-bit random object reference. The encryption key NEVER enters the API request; it is in `/#/receive/{reference}/{key}`. URL fragments are not sent in HTTP requests. A recipient removes the incoming key from the visible address bar using replaceState and keeps it in memory; a refresh loses it. Preserve the original secret link to reopen.

The full link is a bearer capability. Anyone holding it can download/decrypt before expiry. The separate deletion token is stored locally in a receipt and sent only in the Authorization header on DELETE. No server-side decryption is possible through this protocol. The relay does not receive or store the decryption key. IP addresses, timing, ciphertext length and expiry are NOT hidden. Browser extensions, compromised client code and shared-link recipients are outside this encryption boundary.

## API (same-origin routing required)

- GET `/api/shares/health`: protocol/version and upload availability.
- POST `/api/shares`: binary body, `X-Neuron-Client: 1`, `X-Neuron-TTL`, `X-Neuron-Delete-Hash`. Returns reference and server expiry timestamp.
- GET `/api/shares/{id}`: bounded ciphertext; no deletion metadata returned.
- DELETE `/api/shares/{id}`: `Authorization: Bearer {deletion token}` and application header. Successful deletion returns 204.

All API responses are no-store. The service worker bypasses this prefix. Mutation requests must have an explicitly allowed browser Origin and application header. This is CSRF/origin hardening, NOT authentication against non-browser clients that can forge headers. No-account anonymous upload always requires abuse/billing oversight; do not call it abuse-proof.

Limits: encrypted envelope <=8 MB +64 bytes. Allowed TTLs: 60, 900, 3600, 86400 seconds; UI exposes 15 minutes/1 hour/24 hours. Download checks enforce expiry immediately; hourly cron physically removes expired objects even if never fetched. Provider backup/retention policy still applies. A scheduled delay does not grant post-expiry downloads through this API. Revocation cannot remove already-downloaded copies or plaintext exports.

A single transactional Durable Object enforces fixed-hour budgets: per-client upload 3, download 30, delete 20; global upload 50, download 500, delete 500. A salted hash of Cloudflare's connecting IP is used, not raw IP in application storage. The worker secret must be strong in production. Global budgets bound successful new client entries; NAT users share limits. These budgets do not cap every possible edge/R2/DO billing cost, and are not a replacement for provider rate controls, alerts and a kill switch. Failed reservations are not refunded to prevent retry abuse.

The server can validate envelope framing/size, NOT prove ciphertext decrypts to a model: it lacks the key. The official client encrypts only whitelisted model content. A malicious direct API client can upload arbitrary bytes disguised as an envelope; governance/abuse controls remain necessary. Expiry and deletion are capabilities, not account recovery.

Receipts live in a SEPARATE IndexedDB database so deleting a project does not lose revocation access automatically. They contain both link and deletion secret. Download them privately. Project backups deliberately omit them. Import receipts only into the same app origin. Forget local receipt is NOT revoke. Clearing browser data without exporting a receipt loses early-revocation access, while expiry remains enforced.

## Deployment

Worker implementation: `services/relay/src`; R2 binding SHARES; SQLite-backed Durable Object LIMITER; scheduled cron. `wrangler.toml` fails closed with uploads disabled. The bucket name is a real resource to provision, not a credential. Keep the R2 bucket private: never enable a public bucket endpoint that bypasses API expiry/deletion. Set exact production ALLOWED_ORIGINS; generate a >=32-character random RATE_SALT using the provider secret manager. Enable uploads only after setting billing alerts, edge rate controls, retention review and tests. Deploy via a reviewed Wrangler installation under Node 22.12+; no deployment is performed by local scripts.

Static frontend and API must share the browser origin. Route `/api/shares*` to the Worker at the provider; do not rely on Vite's development proxy in production. The existing public/\_headers needs host-specific application. Do not ship storage credentials or RATE_SALT in frontend/VITE variables. Do not log full links, fragments, Authorization headers or receipt JSON. Configure access logs and error monitoring accordingly. Cloudflare infrastructure may retain connection metadata independently.

Local Miniflare uses actual Worker/R2/DO runtime behavior but is NOT a public production deployment. It listens on 8787, with ciphertext state under services/relay/.local (gitignored). That state is development-only and may disappear in ephemeral sandboxes or manual cleanup. Web dev and production-preview proxies use server-only NEURON_RELAY_TARGET, default http://127.0.0.1:8787. Browser code always uses relative paths. Local dev allows localhost and HTTPS \*.e2b.app origins; production does not inherit that wildcard.
