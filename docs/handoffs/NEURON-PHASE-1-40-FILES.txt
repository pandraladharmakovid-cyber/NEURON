WHAT THIS PHASE DOES NOT CLAIM
------------------------------
This is an implemented image-classification phase, not the entire completed product
or a promise of a perfect production application. No fabricated functionality is used.

Still to implement: service-worker offline reload, cached model asset packs,
worker-isolated training, robust large-dataset/resource scheduling, independent test
sets and deeper leakage detection, encrypted asynchronous share links, WebRTC,
text/audio/tabular/video adapters, feedback-driven evolution, dataset backup/restore,
full deployment automation, security/accessibility audits and a verified device matrix.
The six modality tiles on the homepage are a noninteractive decorative preview;
only image classification is active, with the others explicitly labeled Later phase.

The encoder requires network access on the first training/inference in each fresh
page session. Subsequent use reuses the in-memory encoder. Do not advertise full
offline support. Browser HTTP caching is not a guaranteed offline asset strategy.
Training yields asynchronously but is not moved to a Web Worker in this phase.
Camera predictions are triggered by the Predict this frame button, not continuous
streaming inference. No camera or microphone data is silently uploaded.

Validation accuracy is not an independent test score, and softmax scores are not
calibrated probabilities. Near-duplicate images can inflate validation results.
Five samples/class is a minimum for functionality, not enough for most useful models.
A seed fixes split and initialization, but GPU execution / fit shuffling need not be
bit-for-bit deterministic across runs or hardware.

Model imports into an existing project require confirmation: the incoming vocabulary
replaces project classes and its dataset is cleared. Old model versions remain usable.
Export your models and keep original images separately. Browser storage can be evicted.
Model exports do not constitute dataset backups and may leak learned information.

Public/_headers supplies header rules for hosts that understand that format. It is
NOT applied by every host (including Vercel) and is not a Vite development-server CSP.
Before hosting, configure equivalent actual response headers for the chosen provider,
verify the Google/Kaggle model-download redirect chain, and test camera permissions.
Do not deploy the existing scaffold's infra/vercel.json as if it were implemented.

# NEURON — Phase 1

A real local image-classification workflow. No account or API key required.

## Run

Install Node.js 20.19+ or 22.12+. With pnpm 9 available:

    pnpm install
    pnpm dev
    pnpm typecheck
    pnpm test
    pnpm build

Open the URL printed by Vite. Use Chrome/Edge desktop for the initial support target. Camera requires HTTPS or localhost. A WebGL-compatible browser is recommended. Training can fall back to the much slower TensorFlow.js CPU backend. Allow time for the initial MobileNet download; an internet connection is required for each fresh page session's first encoder load in this phase.

## What works

Create/delete local projects, add/rename/delete classes, import JPEG/PNG/WebP, remove samples, real MobileNet transfer-learning, stratified held-out validation, real epoch progress/cancellation, confusion matrix, IndexedDB model history, activate/rollback, JSON model export/import and local file/camera inference. Camera mode predicts individual frames on request, not a continuous streaming pipeline. Training uses a frozen MobileNet embedding and a newly trained dense classifier; it is not foundation-model training.

A class needs at least five samples; diverse examples (30+ per class) are strongly recommended. Validation is held out from fitting, but is not an independent test set and must not be presented as final generalization performance. Do not split near-duplicate frames across classes/validation.

## Privacy and persistence

Images and training stay in this browser. The image encoder weights are fetched from Google's model distribution endpoints; those requests expose connection metadata, never your samples. Imported images are decoded and re-encoded to a bounded JPEG before storage (metadata is not preserved). IndexedDB is browser-profile storage, not a durable backup. Private browsing, eviction, clearing site data or changing origins can remove access. Exported model files contain weights and class labels, not your source images; they do NOT back up the dataset. Models may still leak training information.

## Phase boundaries

This phase does NOT implement a service worker/full offline reload, encrypted share links, WebRTC, worker-based training, non-image modalities, automatic model evolution, or a cross-browser certification. The UI does not pretend these exist. TensorFlow.js training remains on the browser thread with asynchronous yields; large jobs can still affect responsiveness. Frozen encoder assets are fetched using @tensorflow-models/mobilenet. Use only images you have rights to process. Model asset licensing/distribution and a real-device GPU/memory audit remain release gates.

Dataset state and model versions are persisted; camera streams are stopped on unmount. Interrupted training is not resumable; the previous saved model remains intact. Stored models are immutable version artifacts. Export imports are schema/shape/size checked; arbitrary model code/topologies are never accepted. A model imported into another project replaces its class vocabulary and clears that project's existing dataset after explicit confirmation in Settings.

## Agent handoff

The Phase 1 text bundle is authoritative for its 40 files only. Preserve the other scaffold files, but do not import their stubs or claim they work. Lockfile is produced by the real installation and should be committed after review. Do not invent test results. Tests cover pure validation/splitting/metrics and artifact rules; real-browser training and camera require the manual checks in the supplied handoff text.

import { Component, type ReactNode } from "react";
export class ErrorBoundary extends Component<
  { children: ReactNode },
  { error: string | null }
> {
  state: { error: string | null } = { error: null };
  static getDerivedStateFromError(error: Error) {
    return { error: error.message };
  }
  render() {
    return this.state.error ? (
      <main className="fatal">
        <h1>NEURON needs to restart</h1>
        <p role="alert">{this.state.error}</p>
        <p>Your previously saved projects have not been deleted.</p>
        <button onClick={() => location.reload()}>Reload application</button>
      </main>
    ) : (
      this.props.children
    );
  }
}

import { openDB, type DBSchema } from "idb";
import type { Project, Sample, ModelVersion } from "./types";
interface NeuronDB extends DBSchema {
  projects: { key: string; value: Project };
  samples: { key: string; value: Sample; indexes: { "by-project": string } };
  versions: {
    key: string;
    value: ModelVersion;
    indexes: { "by-project": string };
  };
}
let connection: ReturnType<typeof openDB<NeuronDB>> | undefined;
export function database() {
  if (!("indexedDB" in globalThis))
    throw new Error(
      "This browser does not support IndexedDB. Use a normal Chrome or Edge window.",
    );
  return (connection ??= openDB<NeuronDB>("neuron-local", 1, {
    upgrade(db) {
      db.createObjectStore("projects", { keyPath: "id" });
      db.createObjectStore("samples", { keyPath: "id" }).createIndex(
        "by-project",
        "projectId",
      );
      db.createObjectStore("versions", { keyPath: "id" }).createIndex(
        "by-project",
        "projectId",
      );
    },
    blocking() {
      connection?.then((db) => db.close());
      connection = undefined;
    },
    terminated() {
      connection = undefined;
    },
  }));
}
export async function saveProject(project: Project) {
  await (await database()).put("projects", project);
}

export function random(seed: number) {
  return () => {
    seed |= 0;
    seed = (seed + 0x6d2b79f5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;

}
export function splitIndices(labels: number[], seed: number) {
  const rng = random(seed),
    train: number[] = [],
    validation: number[] = [];
  for (const label of [...new Set(labels)]) {
    const indices = labels
      .map((v, i) => (v === label ? i : -1))
      .filter((i) => i !== -1);
    if (indices.length < 5)
      throw new Error("Every class needs at least 5 images.");
    for (let i = indices.length - 1; i > 0; i--) {
      const j = Math.floor(rng() * (i + 1));
      [indices[i], indices[j]] = [indices[j], indices[i]];
    }
    const count = Math.max(1, Math.floor(indices.length * 0.2));
    validation.push(...indices.slice(0, count));
    train.push(...indices.slice(count));
  }
  return { train, validation };
}
export function evaluate(
  actual: number[],
  predicted: number[],
  classes: number,

  if (!actual.length || actual.length !== predicted.length)
    throw new Error("Invalid evaluation data.");

    Array<number>(classes).fill(0),
  );
  let correct = 0;
  actual.forEach((a, i) => {
    const p = predicted[i];
    if (
      a < 0 ||
      a >= classes ||
      p < 0 ||
      p >= classes ||
      !Number.isInteger(a) ||
      !Number.isInteger(p)

      throw new Error("Invalid prediction index.");

    if (a === p) correct++;
